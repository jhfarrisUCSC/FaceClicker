# FaceClicker

A project template for creating games involving clicking faces.

Uses Phaser 3.80

Art assets from the [Shape Characters](https://kenney.nl/assets/shape-characters) asset pack by [Kenney Assets](https://kenney.nl/), with gratitude.

Click start and at the top of the game screen is a face in a purple circle. Find an identicle face in the square grid before before time runs out to gain points. If time runs our or if you choose the wrong face, you lose a life. Lose all three lives and it's game over. For each correct face selected, the grid increases to a max of 6x6.
